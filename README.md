## Хийсэн ажил
 SauceDemo (https:/www.saucedemo.com)  дээр Playwright ашиглан 3 тест бичсэн:
 1. Амжилттай нэвтрэх ба гарах
 2. Буруу нууц үгээр нэвтрэхэд алдааны мессеж гарах
 3. Нэвтэрсны дараа бараа сагслаж гарах 
 
 Тест файл: tests/mytest.spec.ts. Код дотор алхам бүрийг коммент бичиж тайлбарласан.
 
 
### Locator, assertion
 - Locator: getByPlaceholder, getByRole, getByText, data-test атрибут.
 - Assertion: toBeVisible(), toHaveURL(), toHaveText().
 - XPath-аас зайлсхийсэн. Учир нь XPath нь HTML-ийн бүтцээс хэт хамааралтай тул хуудасны бүтэц бага зэрэг өөрчлөгдөхөд хугардаг, уншихад хэцүү байдаг. Харин getByRole, getByText нь хэрэглэгчид харагдах зүйлээр элементийг олдог тул тогтвортой, ойлгомжтой байсан.

### Тестийн үр дүн

Нийт 9 тест (3 тест × chromium, firefox, webkit) — 9/9 passed.

### Trace viewer ажиглалт

Trace viewer дээр тестийн алхам бүр (Navigate, Fill, Click, Expect) хугацаатай нь, тухайн мөчийн DOM snapshot-той нь харагддаг. Ингэснээр аль алхамд, ямар locator дээр алдаа гарснийг шууд олж харах боломжтой байсан.
 
 
Playwright ба Selenium -ийн ялгаа

 Playwright нь auto-wait-тай тул элемент бэлэн болтол автоматаар хүлээдэг. Selenium дээр explicit wait-ийг гараар бичих шаардлагатай байдаг.
Суулгалт хялбар: npm init playwright@latest болон npx playwright install гэсэн командаар төсөл болон хөтчүүд (Chromium, Firefox, WebKit) бүгд суудаг. Selenium-д хөтөч бүрд тусдаа driver тохируулах шаардлагатай.
Нэг тестийг 3 хөтөч дээр зэрэг ажиллуулж, кроссбраузер шалгалтыг хялбар хийж болсон.
Trace viewer нь алхам бүрийн бичлэг, DOM snapshot-ыг үзүүлдэг тул алдаа олоход Selenium-ийн лог, screenshot ноос илүү тустай санагдсан.
getByRole, getByPlaceholder зэрэг locator нь уншихад ойлгомжтой, тестийн код цэвэр харагддаг.
Selenium нь олон жилийн түүхтэй, олон хэл болон хэрэгслийг дэмждэг, нийгэмлэг нь том. Playwright нь шинэ боловч хурдацтай хөгжиж байгаа.
Аль аль нь Apache 2.0 лицензтэй үнэгүй, нээлттэй эхийн хэрэгсэл.
Миний хувьд Playwright илүү хурдан тохируулж, алдаа олоход хялбар санагдсан.
